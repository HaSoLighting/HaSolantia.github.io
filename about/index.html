About

About HaSolantia

HaSolantia is an independent technical practice focused on architectural lighting analysis, photometric simulation, research, technical documentation, and practical learning for the built environment.

What We Do

HaSolantia supports architects, designers, project teams, researchers, educators, and other clients who need clear lighting analysis, simulation, research, or technical documentation for a defined project scope.

Mission

To make lighting analysis and technical knowledge clear, practical, and evidence-based while delivering dependable project support and useful documentation.

Vision

To develop a trusted technical practice that supports better lighting and building-performance outcomes, especially in environments where infrastructure challenges, technical knowledge gaps, and affordability constraints are significant.

  • Photometric simulation
  • Lighting analysis
  • Visual comfort
  • Energy evaluation
  • Technical research
  • Data analysis
  • Design documentation
  • Technical education
