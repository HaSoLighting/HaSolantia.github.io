Project Inquiry

Tell us about your project.

Use this form to request lighting analysis, photometric simulation, architectural lighting support, technical research, data analysis, or project documentation. Providing clear project information helps HaSolantia evaluate the requested scope, available resources, schedule, and appropriate deliverables.

Project Process
What Happens Next
  1. The submitted project information and available documentation are reviewed.
  2. HaSolantia may request additional information or clarification before defining the scope.
  3. If the project is a suitable fit, a written scope identifies the services, deliverables, assumptions, schedule, and fee.
  4. Work begins only after the project scope and commercial terms are accepted.
Before You Submit
Helpful Project Information

The following information can help us assess your project more efficiently.

  • Project type and location
  • Current project stage
  • Requested service and deliverables
  • Available drawings, models, specifications, or IES files
  • Applicable criteria or standards
  • Desired completion date

Professional notice: HaSolantia provides technical analysis, research, documentation, and design-support services. Services requiring professional engineering licensure, certification, or stamped engineering documents must be performed or approved by an appropriately licensed professional.
